# Save 0.4.1 · 原版请求对齐版

以 Lol1p0p/narrative-agent 0.2.1 提交 `29a86d7323eb409131fdb28d926e3ea451eccb5c` 为基础。

## 这次修正

- 撤销 0.4.0 新增的角色卡全文注入。角色信息、预设和用户设定完全沿用原版路径，不额外添加角色字段。
- 启用开关单独保存，关闭原版不再让本版继承关闭状态。首次使用本版默认启用，以后尊重本版自己的开关选择。
- 显示“接管已开启/已关闭”和本页接管次数，方便确认当前是否进入了原版中继流程。
- 保留隐藏末尾“轮次、用户意图、叙事要点”的显示补丁，内部摘要照常保存和使用。
- 保持插件不读取内嵌或外部世界书。

## 安装或上传 GitHub

ZIP 根目录只有一套当前文件。**解压后全部上传到 GitHub 根目录，与 manifest.json 同级，覆盖同名文件。** 不要上传 ZIP 本身，不要多套文件夹，不要只挑几个文件。

在酒馆扩展管理中禁用其他旧 Save 和原 Narrative Agent，只启用这一份；更新后刷新网页，应看到 **Save 0.4.1 · 原版请求对齐版**。

面板勾选“启用多Agent叙事系统”，发送一条消息后，状态应显示“本页已接管 1 次”（以后逐次增加）。本版自己的开关不再跟随原版开关。

保留原版摘要/状态数据命名空间，不删除聊天、摘要或旧版本文件。启用配置使用单独的 save-original-minimal 键；其他原版偏好在首次使用时继承，原版的关闭状态不继承。

## 与原版的对照

在相同设置、无世界书的合成聊天中，原版与本版的 **Relay、正文、摘要三次完整请求体逐项相同**；普通和召回模式的插件出口请求也逐条相同。计费插件显示的 input 与原版一致。

不同分词器可能显示不同的具体数字。本版恢复原版请求，不修改计费插件、token_count、API 用量、模型上限或采样参数。计费插件面板只计入中继的数值仍不是整轮全部用量。
