# Save 0.3.0 · 原版源码裁剪版

此包是 GitHub 上传用的运行文件包。运行代码与完整 save-v0.3.0.zip 一致，未修改插件逻辑；已排除测试、原版对照源码及开发记录。

## 上传 GitHub

1. 解压 save-v0.3.0-github.zip。
2. 将解压出的全部文件直接上传到插件仓库根目录，与原来的 manifest.json 同一层。
3. 保持文件名不变，覆盖同名文件并提交。本包不需要再套一层 save 文件夹，也不是将 ZIP 本身作为插件上传。
4. 酒馆通过原来的仓库地址更新扩展，刷新后确认设置面板显示 Save · 原版源码裁剪版 0.3.0。

manifest.json、index.js、compat.js、style.css 等文件应在同一层。请关闭原 Narrative Agent 及重复安装的旧 Save，保证只启用一份接管插件。

## 使用范围

沿用 Narrative Agent 0.2.1 的 Relay、raw 生成、逐轮摘要和近期窗口；支持当前聊天原文召回。普通模式通常 3 次模型请求，召回通常 4 次，首次开场分析与技术故障恢复另计。

聊天页面只显示原生正文与按原生开关读取的思考；内部仍保留正文/摘要数据供恢复使用。删除世界书读取、骰子、任务、库存、数值游戏状态、MVU 和工具执行。

旧 0.2.3 的有效摘要可读取，不需要清空聊天。显示未确认保存时先导出恢复备份。内容拦截会显示具体阶段和原因，不会自动改写内容、换模型或修改安全设置重试。

本包运行代码已通过 40 项离线检查及独立 SillyTavern 1.18.0 真实前后端的 53 次本地模拟模型请求。未使用用户实际付费接口或 Android 实机验证。完整测试与原版对照保留在完整源码包中。
