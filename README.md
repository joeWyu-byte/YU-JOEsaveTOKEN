# Save 0.5.0 · 原生聊天版

基于 Lol1p0p/narrative-agent 0.2.1，固定提交 `29a86d7323eb409131fdb28d926e3ea451eccb5c`。

此版本针对手机浏览器中的普通角色聊天：保留原版摘要、上下文窗口、检查点与原文召回，保留酒馆原生聊天排版及实际回复对应的思考。

## 安装与 GitHub 上传

1. 解压本 ZIP，将根目录的全部文件上传到你的插件 GitHub 仓库根目录，覆盖同名文件。`manifest.json` 与 `index.js` 必须在同一层。
2. 不要上传 ZIP 本身，也不要套上另一层文件夹。包内只有一套当前文件，没有旧版本副本。
3. 在酒馆扩展管理中禁用原 Narrative Agent 和其他旧 Save，只启用这一份。更新后刷新网页，面板应显示 **Save 0.5.0 · 原生聊天版**。
4. 勾选“启用省 Token 聊天”。原文召回按需使用；开启后沿用原版的规划与召回流程。

没有修改角色卡、预设原文件或聊天主题。启用配置继续沿用 Save 0.4.1 的独立配置键，摘要和检查点沿用原版命名空间；没有删除旧聊天及旧版本文件。

## 改动对应的需求

- 隐藏聊天末尾的“轮次、用户意图、叙事要点”，内部 `<summary>` 仍保存并用于压缩。
- Relay 占位请求仍与原版一致，但临时消息和它的思考不会显示为角色回复。执行进度只显示在扩展面板。
- 通过酒馆原生数据接口读取实际正文请求返回的思考，使用原生思考折叠显示。服务商没有返回思考时不编造，也不沿用 Relay 思考。
- 正文直接使用酒馆本轮编译出的角色卡、用户设定、已启用预设、示例、作者注及消息顺序；不额外添加“叙事引擎”或“思维模式要求”。
- 已有可靠摘要的旧历史按原版窗口压缩；未摘要的历史保留原文，避免摘要失败后静默丢失上下文。
- 插件世界书读取入口返回空；启用时阻止原生世界书激活内容进入提示。角色卡与用户设定正常保留。
- 停止会中止正在进行的原生 raw 请求。实际正文一旦返回即保留；摘要、检查点或保存失败不会触发重新写一份正文。
- 同步原生滑动分支的正文、摘要和思考。切换聊天或编辑消息后，迟到结果不能覆盖新内容。
- 保存继续调用酒馆原生接口。因为该接口内部会捕获错误，本版只观察保存响应状态，避免将失败误报为成功；不改请求、不使用另一条保存 API。

## Input 和实际用量

原版 Relay 的两条短消息逐字保留，没有修改计费插件或伪造 Token 数字。本地同一 Token Usage Tracker 显示 **Input=48**，与之前核实的原版基线一致；具体计数会随分词器和酒馆版本变化。

这个小数字只覆盖计费插件捕获的中继请求。正常流程另有正文与摘要请求，开启召回时还会有规划请求，整轮真实用量应以接口记录为准。保留角色卡和预设需要相应输入，不能把中继数字当成全部费用。

## 验证范围

19 项离线检查、24 个运行时脚本语法检查通过。独立 SillyTavern 1.18.0、390×844 手机视口、本地模拟接口完成 12 类集成检查，覆盖流式 Relay、实际正文思考、提示内容与参数对照、各阶段停止、召回、多轮压缩、滑动、续写、重生成、保存失败、聊天切换和刷新恢复。

正文仍沿用原版 raw 请求的非流式返回时机；实际回复返回后显示其思考，不新增另一条生成思考的请求。测试没有调用真实付费模型，也没有代替用户手机上的实际验证。模型文风验收依据是保留用户生效的提示信息，不能由模拟回复证明真实模型每次措辞相同。
